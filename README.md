# SaaS Payment

SaaS Payment 是一个面向 SaaS 产品的会员订阅支付系统项目，采用 specification-first 的方式，先明确业务规则、支付流程、安全要求和实施路径，再进入工程实现。

第一版目标是完成桌面 Web 场景下的会员支付闭环：

> 微信扫码登录 → 选择月付会员 → 创建订单 → 微信/支付宝支付 → 支付回调验签 → 开通或续费会员 → 后台管理订单、退款、发票和会员状态。

## About

SaaS Payment 是一个面向 SaaS 产品的会员订阅支付系统项目，规划支持微信扫码登录、月付会员、微信支付、支付宝支付、会员权益、退款、发票申请、微信通知和管理后台。

当前仓库处于 specification-first 阶段，已完成支付系统规范文档，后续将逐步实现前后端分离的完整工程。

## 项目目标

- 支持用户通过微信扫码登录。
- 支持单一月付会员套餐。
- 支持微信 Native 扫码支付。
- 支持支付宝电脑网站支付。
- 支持会员开通、续费、7 天宽限期和权益判断。
- 支持后台维护套餐价格、查询订单、处理退款和发票申请。
- 支持支付回调验签、幂等处理、审计日志和微信通知。

## 第一版范围

### 必须包含

- 微信开放平台扫码登录。
- 单一月付会员。
- 后台维护会员价格。
- 微信 Native 扫码支付。
- 支付宝电脑网站支付。
- 支付成功后自动开通或顺延会员。
- 会员到期后 7 天宽限期。
- 后台订单查询与手动退款。
- 退款成功后扣回该订单贡献的会员时长。
- 用户发票申请记录。
- 微信公众号模板消息或订阅消息通知。
- 支付日志、通知日志和后台审计日志。

### 暂不包含

- 自动续费。
- 多会员等级。
- 手机 App 支付。
- 微信小程序支付。
- 电子发票 API 自动开票。
- 多管理员角色权限。
- 企业级审批流。
- 优惠券、余额、积分体系。
- 部分退款。
- 团队或组织账号。

## 核心业务规则

- 用户必须登录后才能购买会员。
- 用户唯一身份使用微信 `UnionID`。
- 第一版会员周期为 30 天。
- 用户未到期时续费，从当前到期时间顺延 30 天。
- 用户已过期后续费，从当前时间重新计算 30 天。
- 会员到期后进入 7 天宽限期，宽限期内仍可使用高级功能，但需要提示续费。
- 未支付订单 15 分钟后自动关闭。
- 支付状态必须以服务端验签后的支付回调为准。
- 支付宝 `return_url` 只用于页面展示，不能直接确认支付成功。
- 退款成功后立即扣回该订单贡献的会员时长。

## 安全提示

支付项目不得提交任何真实密钥或证书，包括但不限于：

- `.env` / `.env.*`
- 微信支付私钥、平台证书、商户证书
- 支付宝应用私钥、公钥证书
- JWT secret
- 数据库密码
- 生产商户配置

本仓库只应提交代码、规范文档、示例配置和不含真实敏感信息的开发资料。
